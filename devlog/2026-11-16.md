# Day 1 · 2026-11-16 (일) — 나무늘보, 인스타를 만들다 🦥

> 한 줄 요약: 인스타 아이디를 고민하다가 '나무늘보'가 되고, '빌딩늘보'라는 꿈이 생기고, 프로필 캐릭터를 만들기 시작한 날.

### 🎒 늘보가 태어날 때 가지고 있던 것
- 코딩 실력: 0
- 만든 것: 아직 없음
- 💰 수익: 0원

## 1. 인스타 아이디 고민
🦥 "나중에 모아서 인스타 업로드 할꺼야 인스타 아이디 를 뭘로 할까"
🤖 아이디 후보 여러 개를 추천

🦥 "Avian Influencer 를 활용해봐"
🤖 `@avian.influencer` 등 후보 ('새 인플루언서')

🦥 "코딩모르는 1인개발자"
🤖 콘셉트로 딱이라며 소개 문구 작성: "💻 코딩 1도 모름 · AI랑 게임 만드는 중"

## 2. "Tree null vo" 사건 😂
🦥 "Tree null vo"
🤖 "아이디로 쓰실 건가요? null은 프로그래밍에서 '값이 없음'이라는 뜻인데…" (진지하게 분석함)
🦥 "나무늘보"
🤖 "아, 나무(Tree) + 늘보(null vo) = 나무늘보였군요!"

→ AI가 말장난을 못 알아듣고 진지하게 분석함. 코딩 용어 null이 들어가서 '코딩 모르는 개발자' 콘셉트와 묘하게 맞아떨어짐.

🦥 "tree_null.vo로 했어" → **인스타 가입 완료: `@tree_null.vo`**

🎬 **릴스 소재 (강추)**: 채팅 재연 — "Tree null vo" → AI 진지한 분석 → "나무늘보" → 깨달음. 제목 예: "AI한테 내 아이디 뜻 맞혀보라 했더니"

## 3. 인스타 자동 업로드 알아보기
🦥 "인스타 자동업로드 스킬있어?"
🤖 플러그인 목록에서 Posty, post bridge 등을 찾음. 업로드는 프로페셔널 계정 전환 + 연결이 필요하고, 올리기 전엔 항상 확인받기로 함. 지금은 영상 모으는 단계라 나중에.

## 4. 콘셉트 확정: 빌딩늘보 🏢
🦥 "우리 인스타 컨셉은 코딩을 모르는 나무늘보가 AI를 통해 게임, 앱, 영상, 3D 캐릭터 등으로 수익을 내며 '빌딩늘보'가 되는 것을 꿈꾸는 컨셉이야."

- 빌딩늘보 = 건물주가 되고 싶은 늘보 + 무언가를 building(만드는) 늘보
- 콘텐츠 기둥: 🎮 만들기 · 📅 늘보 일지 · 💰 수익 기록(0원부터 솔직하게) · 🤖 AI 활용법
- 끝 인사: "빌딩늘보가 되는 그날까지… 느려도 다음 주에 또 만나요 🦥🏢"

## 5. 개발 일지 시작
🦥 "우리가 하는 대화내용도 인스타 릴스 영상으로 쓸수있어? 따로 내가 기록해야해?"
🤖 대화는 길어지면 요약돼 사라질 수 있으니 저장소에 남기자고 제안
🦥 "오늘 11월 16일 부터 시작하자" → 이 일지 시작!

## 6. 프로필 캐릭터 만들기 시작
🦥 "아직 웹 게임 개발 안 한 거야. 나중에 차근차근 넣을 거야, 알겠지? 오늘 인스타 아이디 만들고 캐릭터 만드는 것부터 시작이야. 그러니 이제 프로필 캐릭터 만들기부터 하자."
