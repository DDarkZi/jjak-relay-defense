# AI 3D 모델 출처·이용 조건 메모

- 만든 곳: Hyper3D **Rodin** (운영사 Deemos Corporation), 2026-11-09 생성
- 입력 그림: 우리가 Gemini(나노 바나나)로 만든 유닛 일러스트 (`art_src/units/`)
- 파일: `chick_rodin_shaded.glb`(원본 12만 면) → 게임용으로 줄인 뒤 Blender로 뼈대·애니메이션을 넣어 `assets/models/chick_anim.glb`(옛 정적 chick.glb는 2026-11-11 삭제)

## 이용약관 확인 (hyper3d.ai/legal/terms, 2026-11-09에 사용자가 캡처해 확인)
- 5조 (b) Rodin: "If you use Rodin to generate Output, we will not limit your use of such Output,
  subject to any restrictions set forth in these Agreements, the Applicable Laws and any third-party terms..."
  → Rodin 결과물은 사용 제한 없음(상업적 이용 포함). 무료/유료 구분 문구는 본 범위에서 없었음.
- 5조 (a) ChatAvatar는 "personal entertainment use"(개인 오락용)만 허용 → **ChatAvatar로는 만들지 말 것.**
- 결과물 저작권 성립 여부는 보증하지 않음. 회사가 Prompts/Output을 약관에 따라 이용할 수 있음
  ("private"로 설정하면 계정 표시 외에는 쓰지 않음).
- 입력(그림)이 제3자 권리를 침해하지 않아야 함 → 우리 자체 캐릭터 그림만 사용.
