# 스토어·공유 그림 만들기
- `og_card.js SP 저장소경로` → 카톡 미리보기 카드(og.jpg, 1200×630). "설치 없이 바로 플레이" 버튼 있음(웹 링크용).
- `feature_graphic.js SP 저장소경로` → 같은 디자인에서 버튼을 뺀 판. 1024×500으로 가운데를 잘라 `assets/store/feature-graphic-1024x500.png`(구글 플레이는 그림 속 '다운로드하세요' 같은 문구를 권장하지 않음).
- `screenshots.js SP` → `SP/store/*.png`(게임 캡처)에 제목·부제를 붙여 1080×1920 스크린샷.
- SP = 작업 폴더(캡처 원본·출력 위치). 새 이름은 '이상한 새 55종'으로 통일(2026-11-10).
