## 2. 좋은 배치로 판단한 것 (근거 순)

1. **업그레이드는 몇 개만 4성, 나머지는 넓게** — 사람은 Lv4가 16개인데 알파고는 31개예요. 알파고 안에서도 **하위권(36개)이 상위권(27개)보다 Lv4가 많아요.** 설계도 B5(사람 업그레이드 순서를 따름)는 11개뿐인데 성적이 좋아요. → "모두 4성"보다 **"강한 것만 4성, 돈은 타워 수에"**가 좋아 보여요. (전에 사용자가 말한 '독 4성 상한' 생각과 같은 방향)
2. **보조 타워를 덩어리로 붙이기(전봇대·비눗방울·회오리)** — 사람 14쌍, 알파고 상위 12쌍, 하위 4쌍. 붙은 쌍이 많을수록 등수가 좋아요. 빙결+뇌전·빙결+폭풍 사람 판은 전봇대를 14~18개 뭉쳐 놨어요.
3. **입구 쪽에 무게 두기** — 사람은 60%를 위쪽 절반에 지어요(알파고 52%). 새가 들어오자마자 감속·넉백을 받으니 뒤쪽 타워가 오래 때려요.
4. **길은 타워로 만들기, 벽은 거의 안 씀** — 35판 중 26판이 벽 0개. 길 길이는 사람·알파고 비슷(35~37칸)해서, 길 길이보다 **무엇을 어디에 붙였는지**가 차이를 만든 것 같아요.
5. **넉백+독 붙이기(독바람)** — 알파고 상위 5.2쌍 vs 하위 1.5쌍. 사람 독바람 판은 12~20쌍.

## 4. 사람 설계도 학습 결과 (v21.0 실험, 게임에는 아직 안 넣음)

- 11-25 독+폭풍 1등 두 판의 **두루미 오기 전 배치·업그레이드 순서**를 설계도 A·B로 만들고, 다 지은 뒤엔 콤보 점수(🧪늪·과자·파리지옥 / 🧼비눗방울·회오리·전봇대 / 🌫️넉백+독 / 길 덮기)로 이어 짓게 했어요.
- 학습 400판(설계도 후보 4명 + 지금 알파고 4명): 설계도 후보 평균 4.17등, 지금 알파고 4.83등. 가장 좋은 **B5(판 B 설계도)** 약 2.3등. 같은 판의 독바람 대장 5.8~7.2등.
- B5가 고른 값: 길 덮기 점수 0, 넉백+독 1.86, 비눗방울 덩어리 0.87, 사람 업그레이드 순서 대부분 따름(0.70).
  → **사람 배치를 출발점으로, 넉백+독을 사람보다 더 촘촘히 붙이는 쪽으로 발전**했어요(9분 넉백+독 19쌍, 사람 15쌍).
- 처음 보는 판 검증(대상 1명 + 지금 알파고 7명, 각 80판 목표): **진행 중**. 중간(각 10판) B5 2.7 · 설계도 A1 2.4 · 독바람 대장 4.1. 판 수가 적어 아직 판단 안 함.

## 5. 다음에 해 볼 것 (제안)

1. 검증이 끝나고 좋으면 설계도 B5(·A1)를 알파고에 넣기 — 사용자 결정 후.
2. **Lv4 상한 유전자**를 독뿐 아니라 모든 조합에 학습시키기(사람 16개 vs 알파고 31개).
3. 빙결+뇌전 사람 판으로 설계도 C 만들기(전봇대 덩어리 + 폭풍 타워) — 알파고가 가장 약한 조합.
4. 화염 조합에 태양 비중 유전자 실험.
5. 빙결+폭풍 알파고 후보 만들기(사람 1.4등, 알파고 없음).
