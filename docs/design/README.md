# 🐦 새 3D 디자인 개선 기록: '소품 상자(PROP)'와 '날개·꼬리 타입'

> 새떼 주의보: 짹짹 디펜스 · 2026-11-20 · v17.1 ~ v17.3
> Claude(Claude Code)가 코드로 만든 3D 새 모델을 **디자인 팀 회의 → 부품 라이브러리 → 한 종씩 교체 → 전후 비교 렌더** 순서로 발전시킨 기록입니다.

## 한 줄 요약
예전에는 새마다 **공·원뿔·상자를 몸 좌표에 직접 쌓아서** 소품과 날개를 만들었습니다. 이것을 **미리 잘 만든 부품(소품·날개·꼬리)을 '붙는 점(소켓)'에 끼우는 방식**으로 바꿨습니다.
이렇게 바꾸니 모양이 좋아졌고, 소품이 날개를 따라 같이 움직이게 됐고, 같은 부품을 여러 새가 다시 쓸 수 있게 됐습니다.

## 1. 왜 바꿨나 (문제)
| 문제 | 원인 |
|---|---|
| 해적갈매기 칼이 '흰 막대'처럼 보임 | 상자 4개로 만든 칼. 외곽선·휨·금속감이 없음 |
| 칼이 날개가 퍼덕여도 허공에 고정 | 소품을 몸 좌표에 쌓은 뒤 메시 하나로 합침(merge) |
| 공중 새 날개가 전부 같은 모양 | 늘린 구 약 7개로 만든 날개 하나를 색만 바꿔 씀 |
| 날개에 하늘색 '형광 테두리' | 팀 색 띠를 날개 앞쪽에 길게 둠 |
| 꼬리가 위에서 보면 '토끼 귀' | 납작한 공 3개 부채에, 가운데 공이 하늘색 팀 색 |

`00_old_wings.jpg`: 바꾸기 전 날개 8종(앞·옆·위·게임 시점)

## 2. 일하는 방식
1. **디자인 팀 회의**(Claude 서브에이전트 4명이 병렬로 분석만 함): 아트 디렉터·캐릭터 디자이너·화면 가독성·플레이어/스토어 담당. 각자 렌더 시트와 48px 축소 줄을 보고 평가했습니다.
2. **설계 결정**
   - 소품은 `PROP.이름()` 함수로 만듭니다. 원점이 곧 붙는 점이고(칼이면 손잡이), 검은 외곽선을 넣고, 크기는 과장합니다(화면에서 짧은 쪽 4px 이상).
   - 소켓: 머리 위·부리·등·허리·왼/오른 날개 끝. 날개 끝 소품은 날개 그룹의 자식으로 붙어서 같이 퍼덕입니다.
   - 날개와 꼬리는 '타입 함수'로 만듭니다. 한 장짜리 `Shape + ExtrudeGeometry`에 베벨·외곽선·끝 색을 넣습니다.
   - 팀 색은 날개 끝 깃 1장에만 둡니다. 체력바가 이미 팀 색이라 그것으로 충분합니다.
3. **한 종씩 교체 + 커밋마다 확인**: 같은 조명에서 앞·옆·위·게임 시점 4칸을 렌더해 BEFORE/AFTER를 나란히 놓고, 실제 게임 화면에서 콘솔 에러 0을 확인합니다.

| 짧은형 | 둥글고 짧음 | 펠리컨·볼트박쥐 |

## 4. 기술 메모 (다른 개발자용)
- **엔진**: Three.js r128, 빌드 도구 없는 순수 JS. 새는 `js/game.js`의 `birdMesh2`(몸·날개·꼬리)와 ART 모듈 `accParts`(새별 소품)가 만듭니다.
- **소품 라이브러리**: `PROP`는 `accGeo` 바로 위에 있습니다. `wingTip(m, side)`은 날개 그룹과 끝 위치를 돌려줍니다. Shape로 만든 날개는 `P.userData.tipX` 값을 씁니다.
- **날개 타입 함수**
  - `seaWing(s,P)`·`raptorWing(s,P)`·`boltWing(s,P)` 모두 같은 틀입니다. 원점은 어깨이고, x 0~1이 날개 길이입니다.
  - 몸 + 끝 색 두 장에, 외곽선(같은 지오메트리를 검은 `BackSide`로 약간 키운 것)을 더합니다.
  - 지오메트리는 `GC(키)`로 캐시해서 새가 많아도 한 번만 만듭니다.
- **꼬리 타입**: 공중 새 기본 꼬리 자리에서 `TT` 표로 타입을 고릅니다. 엉덩이에 붙이고 0.16rad 들어 올립니다.
- **배운 점**
  - 환경맵이 없으면 metalness를 높이면 검게 보이고, emissive를 세게 하면 하얗게 날아갑니다. 은색은 `0xc4d0dc` · metalness .25 · emissive 약하게가 맞았습니다.
  - 날개 앞뒤 폭(y)을 길이 비율대로 줄이면 막대처럼, 너무 키우면 주걱처럼 보입니다. 바다새형은 0.82배가 맞았습니다.
  - 돌 질감(`stoneify`)·재질 무늬(`matFx`)가 팀 색 부품을 칠하지 않게 `userData.noStone`을 붙여야 합니다.
  - 한 줄 안에서 지역 상수(`WTIP`)를 다른 블록이 쓰면 ReferenceError가 납니다. 꼬리에서도 쓰도록 블록 밖으로 올렸습니다.
- **렌더 확인 방법**: Playwright + swiftshader(WebGL 소프트웨어)로 새 하나를 512px 장면에 놓고 4시점을 찍습니다. PIL로 BEFORE/AFTER 시트를 만들고, 48px로 줄인 줄로 폰 크기 가독성도 봅니다.
