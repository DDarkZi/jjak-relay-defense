# 새 체력 재조정 회의 (2026-11-27, 도입 결정 회의 · 분석만)

사용자 요청: 새를 일반 / 효과(빠름·타워 방해·회복·부활·다수 전송)로 나누고 특성에 맞게 체력 조정. 도감 체력 = 게임 체력(코드값 × 2.4 × 일반 0.95 × 새별 보정 hpK).
선택: 체력 표시=체력+보호막 합계 · 분류=일반+효과 5종 · 변경 폭 제한 없음 · 표로 보고 → 확인 후 반영.

## 팀 의견 요약
- 통계: 값 1G당 체력 중앙값 2.8(0.9~8.6). 오리·도도·악어새·타조·플라맹독·철거반장·독수리가 높은 쪽 이상치, 벌새·재채기 까마귀·냉동실 탈출단이 낮은 쪽. 기준식(추정): 일반 ≈ 2.8×값, 빠른 새 ÷속도^0.5, 방해 +0~15%. 환산: 보호막×0.8, 무리 합계×0.85, 분열×0.7, 불사조 ×2×0.8. 채택 기준: 구매 점유율 0.4~2.5배 80%↑, 알파고끼리 200판 2회 반복, 게임 시간 10~15분.
- 밸런스: 분류별 기준(체력/G) 일반 3.0·빠름 3.0(속도 항)·방해 2.7·회복 2.8·부활 2.8·떼 3.6(총합), 값 구간 보정. 대부분 하향(총합 -13%).
- 플레이어: 도감에 ⚪/⚡ 배지·값 100G당 체력, 방해·빠름 새는 체력 낮게. 너무 약함 후보 벌새·불새·혜성매·탈출단·재채기 까마귀 / 너무 셈 후보 오리·딱따구리·도도·시조새·악어새.
- 개발·QA: U의 hp 대신 BAL.hpK(또는 hpK2+스위치 hpV2) 한 곳에서 조정, 도감·게임이 같은 계산 함수 사용, 새에 `kind` 필드로 분류·배지. 위험: 알파고 학습 가정, 보호막·분열·부활 시뮬 오류, 도감 불일치.

## 의견 충돌(사용자 결정 필요)
- 무리 새(벌새·탈출단·혜성매): 밸런스는 낮춤, 플레이어 대표는 "약해서 안 쓰임".
- 전체 하향으로 게임 시간이 짧아질 위험.
- 알통 대장닭·찌르봇 체력(사용자 '다시 정하자').

## 결과
- 사용자 11-27: 제안 거절(200~600G 새는 지금도 체력이 낮다·공중/지상 구분이 안 됨). 찌르봇·알통 대장닭 체력만 상향(v21.10). 나머지는 미반영.
