## 1. 한눈에 보기
| 항목 | 내용 |

| 게임 | 8명이 원형으로 새(유닛)를 다음 사람에게 보내고, 자기 판의 타워로 막는 타워 디펜스. 목숨 100, 마지막까지 살아남으면 우승 |

## 2. AI가 움직이는 구조
- 코드: `js/game.js` 한 파일. AI는 `aiTick(p)` → `act()` 반복.
- **판단 주기**: 알파고 0.3초마다, 한 번에 2가지 이상 행동(`DIFF.A.tick`·`act`). 사람(분당 약 95번)과 비슷하게 분당 약 70번.
- **한 번의 판단(act) 순서**: 돈이 넘치면 새 보내기 → 두루미가 흐트러뜨린 미로 복구 → 수비가 모자라면 업그레이드·건설 → 벽을 공격 타워로 교체 → 약한 타워 재건 → 타워 목표 수까지 건설 → 인컴 목표까지 새 보내기 → 업그레이드 → 여윳돈으로 새 보내기.
- **새 보내기**: `buyU`가 상대(다음 사람)의 수비를 정찰해 점수로 새를 고름. 알파고는 고른 새를 남는 돈이 바닥날 때까지 연속으로 보냄(사람의 '길게 누르기'와 같음).
- **수비**: 난이도별 미로 설계도(`MZ`, 가로 뱀·세로 뱀·혼합 등)를 따라 타워·벽을 쌓음. 길을 많이 덮는 칸·들어오는 새 종류·뚫린 기록을 보고 타워를 고름.
- **공평 규칙**: 알파고 난이도에선 AI도 사람처럼 '수상한 알 연구'(알을 많이 보낼수록 부화 등)가 적용됨.

## 3. 유전자(GK) — 학습으로 정해지는 값
| 묶음 | 유전자 | 뜻 |
|---|---|---|
| 경제 | `inc0`·`incRate`·`uShare`·`keep`·`rush` | 인컴 목표, 새에 돈 쓰는 비율, 모아 둘 돈, 공격 시작 시각 |
| 새 고르기 | `uAir`·`uHeavy`·`uTier`·`uSpec`·`fav{새:가중}`·`efav` | 공중·튼튼·비싼·특수 새 선호, 좋아하는 새 |
| 수비 | `tw0`·`twRate`·`wall`·`def8`·`crisis` | 타워 목표 수, 벽 비율, 수비력 목표, 위기 기준 목숨 |
| 업그레이드 | `upAgg`·`upMax`·(신)`upGate`·`up4` | 얼마나 자주·몇 단계까지·언제부터 |
| 똑똑한 수비 | `wrep`·`tswap`·`adapt`·`learnK`·`crUp`·`crFill` | 벽→타워 교체, 약한 타워 재건, 들어오는 새·뚫린 기록에 맞춰 고르기, 두루미 대응 |
| 상황 판단 | `sLead`·`sTrail`·`sLate`·`sDanger` | 앞서거나 뒤질 때, 후반, 위험할 때 전략 바꾸기 |
| 속성 | `tech`·`tech2` | 속성 5종(화염·빙결·뇌전·폭풍·독) 중 2개 |
| 실험(기본 꺼짐) | `safeK…`·`hstg`(hOpen·hStep·hT0·hT)·`burst`·`burstF`·`wave`·`atkK` | 아래 '5. 실패에서 배운 것' 참고 |
| 플래그 | `fl.scout`·`kz`·`jug`·`flex`·`pzt`·`tdem`·`vary` | 정찰, 킬존, 재배치 미로, 유동 수비, 독뇌전 배치, 칠면조 철거, 다양한 새 |

### 4-1. 초반 오프닝 실험 (11-19, 학습 아님·강제 실험) → v16.6 적용
알파고 1명에게 처음 3분 동안 정해진 방법만 시키고(사람 기록 봇 7명 상대, 60판씩) 비교.
| 방법 | 평균 등수 | 우승 | 3분 인컴 |
|---|---|---|---|
| 기준(지금 알파고) | 4.18 | 3 | 300 |
| 칠면조만 | 3.17 | 11 | 524 |
| **해적갈매기 1마리 → 칠면조** | **2.50** | 15 | 613 |
| 알 타워 철거 → 칠면조 | 2.62 | 10 | 533 |
| 가성비 새 2분 | 3.35 | 8 | 375 |
| 싼 타워 2개 + 칠면조 | 3.45 | 8 | 474 |
| **해적갈매기만** | 2.58 | **20** | **745** |
| 6종 섞기 | 3.82 | 4 | 316 |
- 학습에 안 쓴 기록 3판에서도 기준 3.70등 → 해적+칠면조 1.55등·해적만 1.58등. 초반 수비보다 새(해적·칠면조)에 돈을 몰아야 사람만큼 번다.
- **v16.6 적용**: 사람 학습 알파고 8종에 오프닝 6종을 나눠 주고(해적만 2·해적→칠면조 2·철거→칠면조·싼 타워 2+칠면조·칠면조만·가성비 새 2분) 속성 조합 8개를 겹치지 않게. 검증: 기록 10판 4.18→2.92등(144판, 우승 5%→17%, z≈3.9) · 처음 보는 3판 3.70→2.02등(우승 8%→37%) · 3분 인컴 300→577(성향별 441~711) · 사람 봇 판 게임 9~10분(AI끼리 18.4분). 도입 회의 4명 모두 조건부 찬성(걱정: 해적 쏠림·초반 억울함·폰 성능·게임 시간). 코드 `HUM_OP`·`opTick`(game.js), 비우면 원래대로.

## 5. 실패에서 배운 것
1. **손으로 정한 고정값은 대부분 약해졌다.** (몰아 보내기·안전 송출·단계 수비·초반 배치) → 값은 학습으로 찾게 할 것.
2. **학습 점수가 올라도 따로 검증하면 안 오른 적이 많다.** 사람 기록이 적을 때(8판) 그 판들에 맞춰지는 과적합. → 기록을 학습용/검증용으로 나눌 것.
3. **재생 봇은 실제 사람보다 쉽다.** 기록한 시각에 같은 행동만 하고 상황에 대응하지 못함. 최종 판단은 실제 사람 판.
4. **40판 한 번은 평균 등수가 ±0.33등 흔들린다.** 0.4등 차이를 가리려면 약 200판. 같은 조건 기준선을 같은 날 다시 돌릴 것.
5. **업그레이드를 끊고 그 돈을 모두 새로 보내면 게임이 5분 만에 끝난다**(배운 AI끼리). 다른 난이도에 가르칠 땐 업그레이드 유전자는 빼고 가르침.
6. **속성이 한 조합으로 몰리면 매 판 같은 상대가 된다.** 알파 성향 뽑을 때 속성 조합이 겹치지 않게 함.

## 6. 사람 vs 알파고 — 지금까지 찾은 차이 (사람 기록 10판, 사람 10판 중 9승)
| 지표 | 사람 | 알파고 |
|---|---|---|
| 3분까지 새 송출 금액 | 7,878G | 3,626G |
| 4분 타워 수 | 15~25 (공격 타워 위주, 벽 0~2) | 약 39 (벽 많음) |
| 4분 인컴 | 809~976 | 444 |
| 첫 3분 돈 배분 | 대부분 새 | 새 58%·타워 44% |
| 판 전체 돈 배분 | 새 73%·나머지 업그레이드 | 새 91%·업글 12%·타워 2% |
| 업그레이드 | 5~8분부터, 끝날 때 거의 모두 Lv4 | 미로 완성 전 금지, 대부분 Lv3에서 멈춤 |
| 같은 새 연속 송출 | 알 최대 132마리 한 번에 | 돈을 바로 써서 거의 1마리씩 |
- 핵심: 알파고도 번 돈은 거의 새로 보내지만, **초반 3분에 돈을 타워·벽에 묶어 '버는 양'이 절반**이 됨. 인컴은 새를 보내야 오르므로 눈덩이처럼 벌어짐.
- 사람의 냉기+바람 운영 예: 시작 75초에 참새 전봇대 15개를 2줄로 → 3분부터 얼음 타워 → 7분부터 업그레이드 → 끝에 전봇대 38개·대부분 Lv4. 이 판은 15분대 큰 공세에 무너져 '알파 사람 사냥꾼'(냉기+화염)이 우승.
