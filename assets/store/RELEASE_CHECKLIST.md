## 🧸 쉽게 이해하기
### 앱 파일이 3가지인 이유
- **.aab** = 플레이 스토어에 올리는 상자. 구글이 받아서 폰마다 맞게 포장해 줘요.
- **.apk** = 내 폰에 바로 까는 완성품. 미리 보기용이에요.
- **signing.keystore + 비밀번호** = 앱의 **도장**. 업데이트할 때마다 같은 도장을 찍어야 해서, 잃어버리면 곤란해요. **남에게(Claude 포함) 절대 보내지 않기.**

### 왜 "지문"을 두 번 넣을까? (도장 비유)
- 우리 사이트에는 "이 앱은 내 거예요"라는 **확인 명단**(`assetlinks.json`)이 있어요.
- 앱이 켜질 때 안드로이드가 "앱에 찍힌 도장이 명단에 있나?"를 봐요. 있으면 **주소창 없이** 깔끔하게, 없으면 주소창을 띄워요(앱은 그래도 돌아가요).
- 도장은 두 개예요.
  1. **내 도장**(PWABuilder에서 만든 키) → 명단에 넣었어요 ✅. 내가 직접 깐 apk는 이 도장이에요.
  2. **구글 도장** → 플레이 스토어에 올리면 구글이 자기 도장으로 **다시 찍어서** 나눠줘요. 그래서 이것도 명단에 넣어야 해요 ⬜.
- **지문** = 도장의 생김새를 적은 글자(`AB:12:CD:…`). 공개 정보라 보내도 안전해요.
- 구글 도장 지문 찾는 곳(앱을 처음 올린 뒤에 생김): 플레이 콘솔 → 앱 → **테스트 및 출시 → 설정 → 앱 무결성 → 앱 서명** 탭 → **"앱 서명 키 인증서"의 SHA-256** (아래 "업로드 키 인증서"는 내 도장이라 헷갈리지 않기)

### 내 폰에 apk 깔아 보기
1. zip 압축 풀기 → `.apk` 파일을 **PC 카톡 '나와의 채팅'**(또는 구글 드라이브)으로 폰에 보내기
2. 폰에서 파일 누르기 → "출처를 알 수 없는 앱" → **설정 → 이 출처 허용** → 뒤로 → **설치**
3. Play 프로텍트 경고가 뜨면 **세부정보 더보기 → 그래도 설치** (직접 만든 앱이라 뜨는 정상 경고)
4. 확인: 아이콘이 마스코트 AI인가? 이름이 "새떼 주의보"인가? **위쪽에 주소창이 없나?**
5. ⚠️ 나중에 스토어 테스트 버전을 받기 전에 **이 앱을 먼저 삭제** (도장이 달라서 설치가 막혀요)

## 1단계. 개발자 계정 (아직 없다면 가장 먼저!)
1. https://play.google.com/console 접속 → 개인 계정으로 가입, 등록비 25달러
2. 신원 확인(신분증) + 전화번호 확인 + 안드로이드 폰에 "Play Console" 앱 설치해 기기 확인
3. ⚠️ 신원 확인은 하루~며칠 걸릴 수 있어요. 승인 전에는 앱을 못 만들 수도 있어요.

## 2단계. PWABuilder로 앱 파일(.aab) 만들기
1. https://www.pwabuilder.com 에 게임 주소 넣고 Start
2. Package For Stores → **Android** → Generate Package → Options에서:
   - **Package ID**: `io.github.ddarkzi.jjakdefense` 추천 → ⚠️ **한 번 정하면 영원히 못 바꿔요**
   - App name: `새떼 주의보: 짹짹 디펜스` / Launcher name: `새떼 주의보`
   - Version code `1`, Version name `1.0.0`
   - Display: standalone, 방향: portrait
   - Signing key: **Create new** (비밀번호는 따로 적어 두기)
3. 받은 zip 안의 파일:
   - `*.aab` → 플레이 콘솔에 올릴 파일
   - `signing.keystore` + `signing-key-info.txt` → ⚠️ **절대 잃어버리면 안 됨** (구글 드라이브 등 두 군데에 백업)
   - `assetlinks.json` → 3단계에서 사용

## 3단계. 주소창 없애기(assetlinks) — 앱 안 위쪽 주소창 숨김
- 구글은 `https://ddarkzi.github.io/.well-known/assetlinks.json`(사이트 **맨 꼭대기**)만 확인해요.
  지금 게임은 `/jjak-relay-defense/` 아래라서 **새 저장소가 하나 더 필요**해요.
1. ✅ 공개 저장소 **`DDarkZi.github.io`** 만듦 (2026-11-10) — 첫 페이지(게임으로 이동)·`.nojekyll`·빈 `assetlinks.json`(`[]`) 올림
2. PWABuilder의 `assetlinks.json` 내용을 Claude에게 주면 그 저장소의 `.well-known/assetlinks.json`에 넣어 줌
3. 플레이 콘솔에 앱을 올린 뒤 **설정 → 앱 무결성 → 앱 서명 키 인증서 SHA-256** 값도 추가해야 해요(지문 2개).
- 이걸 안 해도 앱은 돌아가요. 다만 맨 위에 주소창이 보여요. 테스트 중에 고쳐도 돼요.

## 4단계. 플레이 콘솔에서 앱 만들기
- 앱 이름 `새떼 주의보: 짹짹 디펜스`, 기본 언어 한국어, **게임**, **무료**
- 앱 콘텐츠(정책) 답변:
  | 항목 | 답 |
  |---|---|
  | 개인정보처리방침 | 위 privacy.html 주소 |
  | 광고 | 없음 |
  | 앱 액세스 | 모든 기능 제한 없이 이용 가능(로그인 없음) |
  | 콘텐츠 등급(IARC) | 카테고리: 게임 / 폭력: 만화풍 가벼운 폭력(피 없음) / 욕설: 없음 / 사용자 상호작용: 있음(온라인 대전, 채팅 없음) / 위치 공유: 없음 / 디지털 구매: **있음**(깃털 인앱 상품) |
  | 타겟 연령 | **13세 이상** 추천 (13세 미만을 고르면 가족 정책 심사가 추가돼요) |
  | 데이터 보안 | 수집·공유하는 데이터 **없음** (게임 기록은 기기에만 저장) |
  | 뉴스·건강·금융·정부 앱 | 아니요 |
- 데이터 보안 메모: 온라인 대전은 PeerJS 공개 중계 서버로 기기끼리 연결해요(IP가 상대·중계 서버에 보일 수 있음, 개인정보처리방침 3번에 적어 둠). 개발자 서버에 아무것도 저장하지 않으니 "수집 없음"으로 답하는 게 일반적이에요.

| 단계 | 언제 | 무엇 | 상태 |

| 2 | 사람이 꾸준히 올 때 | **보상형 광고 하나만**: "1인 개발자를 도와주세요 🙏" → 보면 **이번 판 깃털 2배**. 억지로 보는 광고는 없음 | ⬜ |
| 3 | 광고가 자리 잡으면 | **깃털 유료 판매**(구글 결제) | 🟡 게임 속 상점은 만들어 둠(☕ 개발자 응원 팩 ₩1,000 = 깃털 30개). 콘솔 설정 남음 |

🧸 쉽게 말하면: 깃털 = 영웅을 사는 돈. 깃털은 ① 게임해서 모으거나(우승 2~8개, 져도 등수대로 1~2개) ② 광고를 보고 2배로 받거나 ③ 돈을 내고 살 수 있어요.

2단계 전에 할 일: 웹게임용 광고(구글 H5 Games Ads 등) 신청과 승인, 창문 앱(TWA) 안에서 써도 되는지 확인, 개인정보처리방침·데이터 보안 설문 고치기.
### 🛒 깃털 상점 켜는 법 (게임 쪽은 준비 끝)
🧸 비유: 게임 안에 **가게 진열대**는 이미 만들었어요. 이제 구글에 "이 물건을 이 가격에 팔게요" 하고 **물건 등록**만 하면 돼요.
1. **판매자 등록**: 플레이 콘솔 → 설정 → **결제 프로필** 만들기(정산 계좌, 판매자 정보). 한국은 사업자 정보가 필요할 수 있어요.
2. **앱 파일에 결제 켜기**: PWABuilder에서 .aab를 만들 때 옵션의 **Google Play Billing(Digital Goods API) 켜기**를 체크. 아직 앱을 안 올렸다면 처음부터 켜고 만들면 돼요(이미 올렸으면 version code +1로 새로 만들기).
3. **물건 등록**: 플레이 콘솔 → 앱 → 수익 창출 → 제품 → **인앱 상품** → 만들기
   - 제품 ID: `feather_30` (⚠️ 글자 그대로, 바꾸면 안 돼요)
   - 이름: 개발자 응원 팩 / 설명: 깃털 30개 · 1인 개발자를 응원해요
   - 가격: **₩1,000** → 활성화
   - 두 번째 상품: 제품 ID **`hero_make`** / 이름: 영웅 제작권 / 설명: 내가 만든 3D 새를 게임 영웅으로 / 가격 **₩5,000** (안내·약관: `hero_make.html`)
   - 환불: 저작권 등으로 5회 반려되면 플레이 콘솔 → 주문 관리에서 그 주문을 찾아 환불
4. **시험 구매**: 플레이 콘솔 → 설정 → **라이선스 테스트**에 내 Gmail 추가 → 테스트용 결제(돈 안 나감)로 깃털이 들어오는지 확인.
- 일반 인터넷 창에서는 "앱에서만 구매할 수 있어요"라고 나오고 버튼이 꺼져 있어요(정상).

3단계 전에 할 일: 플레이 콘솔 판매자 정보·정산 계좌 등록(사업자 등록 필요 여부 확인), 구글 결제 붙이기, **구매 복원**(폰을 바꿔도 산 깃털이 사라지지 않게).
