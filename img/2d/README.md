# 2D 그림 파일 넣는 곳

2D 화면은 그림 파일이 없으면 코드로 그린 귀여운 그림을 써요. 직접 만든 그림으로 바꾸려면:

1. 새 그림은 `img/2d/u/<새 id>.png`, 타워 그림은 `img/2d/t/<타워 id>.png`로 넣어요. 예: `u/chick.png`, `t/egg.png`
   - 투명 배경 PNG, 정면(살짝 위에서 본) 모습, 발끝이 그림 맨 아래에 오게 해 주세요.
   - 새는 가로:세로 4:5 정도(예: 256×320), 타워는 8:11 정도(예: 256×352)를 추천해요.
2. `img/2d/sprites.json`에 넣은 id를 적어요. 예: `{"u":["chick","turkey"],"t":["egg"]}`
3. 게임을 새로고침하면 그 id만 그림 파일로 바뀌어요.

id 목록은 `js/game.js`의 `T`(타워) · `U`(새) 배열에 있어요.
